## 关键技术点

1. **DB execution_spec 自动抽取**：`db_spec.extract_database_execution_spec` 从 Vulhub README 解析 SQL 块，无需手写 spec，覆盖了 3 条数据库案例。
2. **compose 端口冲突自动重映射**：`_compose_with_free_host_ports` 检测宿主机端口占用并写临时 yml，CVE-2012-2122 因此顺利起靶。
3. **Windows CRLF 修复**：compose `*.sh` 自动 CRLF→LF，CVE-2018-1058 init.sh entrypoint 因此正常执行。
4. **multi_session 闭环**：CVE-2018-1058 两会话（低权植入+超户触发）走本地 marker 表验证，不依赖外连。
5. **数据库路径 TCP 抓包**：database 执行前后用 dumpcap 抓 `tcp port <db>`，所有 DB 案例均有 pcap 流量证据入 repro。
6. **测后自动清理**：compose down + rmi + network prune，磁盘不累积。
