# CVE Hunter 智能体能力蓝图

生成日期：2026-07-19  
最后更新：2026-07-19（中文状态码 + 数据库优先非 HTTP）

## 1. 目标一句话

在**授权隔离环境**中自动完成：

1. 漏洞与版本取证  
2. 环境发现 / 搭建 / 就绪  
3. 有预算的自主攻击与分层验证  
4. 可重放证据归档与环境回收  

**非 HTTP 策略：优先数据库；其余协议只保留接口，不假装已支持。**

## 2. 八项能力

| # | 能力 | 当前映射 | 状态 |
|---|---|---|---|
| 1 | 情报与版本取证 | NVD / 公告发现 | 部分 |
| 2 | 环境发现与预检 | EnvironmentAgent / env-preflight | 较强 |
| 3 | 环境编排与就绪 | compose up + health + cleanup | 较强 |
| 4 | 攻击规划 | Trigger / Critic | 中等 |
| 5 | 自主执行 | HTTP 发包 + **数据库 execution_spec** | 中等（DB MVP） |
| 6 | 多层判定 | success_tier / status_code / oracle | 已增强 |
| 7 | 可重放归档 | `output/<CVE>/repro/` | 已落地 |
| 8 | 安全边界与回收 | RUN_MODE / reclaim | 较强 |

## 3. 中文状态码（写入 result/batch）

Python 常量名仍为英文，**常量值与对外字段一律中文**。

### 3.1 成功

| 码 | 含义 |
|---|---|
| 检测命中 | IPS 精确命中当前 CVE |
| 目标命中 | HTTP/目标侧 oracle 命中 |
| 数据库命中 | 数据库 oracle 命中 |

### 3.2 常见失败

| 码 | 含义 |
|---|---|
| 参数错误 | CVE 格式错误 |
| 非HTTP漏洞 | 历史兼容；新路径多用「协议未支持」 |
| 协议未支持 | 非 HTTP 且非数据库，仅接口 |
| 情报未找到 / 情报失败 / 情报限流 | NVD |
| 额度耗尽 / 鉴权失败 / 接口限流 / 接口失败 | 外部 API |
| 链接失败 / 搜索失败 / 来源失败 / 无可用PoC | 候选 |
| 发包服务失败 / 目标不可达 / 请求失败 / 抓包失败 | HTTP 执行 |
| 数据库执行失败 / 数据库验证失败 | DB 执行 |
| 仅通用检测 / 仅流量检出 / 目标未验证 / 无利用证据 | 证据不足 |
| 环境失败 | 环境/基础设施 |
| 策略拦截 | RUN_MODE/白名单 |
| 缺前置条件 | 登录/CSRF 等 |
| 复现失败 / 批测异常 | 兜底 |

历史英文码读取时经 `normalize_status_code()` 映射到中文。

## 4. 成功层级（success_tier，中文）

| 层级 | 含义 |
|---|---|
| 连通 | 环境就绪 |
| 已执行 | 至少一次触发执行成功 |
| 目标证据 | 目标/数据库 oracle 命中 |
| 检测证据 | IPS 精确命中 |
| 可复现归档 | 有证据且 repro 完整 + 已回收 |
| 无 | 未达连通 |

## 5. 失败归因（failure_class，中文）

| 归因 | 含义 |
|---|---|
| 无 | 成功 |
| 输入 | 参数/类型/协议不支持 |
| 情报 | NVD/情报 |
| 环境 | 启动/就绪 |
| 前置 | 认证等前置 |
| 候选 | PoC 来源/生成 |
| 执行 | 发包/SQL 执行 |
| 证据 | 已执行无利用证据 |
| 策略 | 策略拦截 |
| 设施 | 代理/服务/批测异常 |
| 未知 | 未映射 |

## 6. 非 HTTP 路线

```text
HTTP（主路径，完整）
  └─ database（优先落地）
       execution_spec:
         engine/version/config
         schema_sql / setup_sql / trigger_sql / cleanup_sql
         oracle: error_pattern | result_contains | crash | row_count
  └─ tcp / kernel / ...（仅接口，返回「协议未支持」）
```

相关代码：

- `cve_hunter/executors/base.py`：协议推断与分发  
- `cve_hunter/executors/database.py`：MySQL/PostgreSQL 执行  
- `RequestExecutor`：识别 `candidate.execution_spec`  
- 类型路由：HTTP 或 database 继续；其它非 HTTP → 归档为「协议未支持」

### 数据库候选来源

1. **自动**：`local_kb` 读 Vulhub README / trickest 文本 → `db_spec.extract_database_execution_spec`  
2. **手动**：候选直接带 `execution_spec`

示例（CVE-2019-9193 自动抽取结果形态）：

```json
{
  "kind": "execution_spec",
  "source": "local_kb_vulhub_sql",
  "execution_spec": {
    "protocol": "database",
    "engine": "postgres",
    "target": "postgres://postgres:postgres@127.0.0.1:5432/postgres",
    "schema_sql": ["DROP TABLE IF EXISTS cmd_exec;", "CREATE TABLE cmd_exec(cmd_output text);"],
    "trigger_sql": ["COPY cmd_exec FROM PROGRAM 'id';", "SELECT * FROM cmd_exec;"],
    "cleanup_sql": ["DROP TABLE IF EXISTS cmd_exec;"],
    "oracle": {"type": "result_contains", "expect": "uid="}
  }
}
```

### 端到端验收记录（2026-07-19）

| 样本 | 环境 | 候选 | 状态码 | 层级 | cleanup | 证据 |
|---|---|---|---|---|---|---|
| CVE-2019-9193（完整工作流） | vulhub/postgres:10.7 :5432 | local_kb 自动抽取 | **数据库命中** | **可复现归档** | passed | `uid=999(postgres)...` |
| 本地 DEMO（执行器链路，缓存镜像） | postgres:9.6-alpine :5433 | README 自动抽取 + DSN 补全 | **数据库命中** | 执行器级成功 | passed | `uid=70(postgres)...` |

说明：第二条为无代理条件下的缓存镜像链路验收；完整 NVD 工作流仍以真实 CVE 编号为主。  
当前代理关闭：若需拉取新的 `vulhub/mysql` 等镜像，应暂停并向用户申请开代理。
