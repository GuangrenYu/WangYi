# 免费优先的信息发现与时间预算

本次方案直接读取公开资料，不运行下载代码或 Nuclei 模板。信息发现使用确定性调度，
模型只负责已有证据到模板的转换，避免给每一次搜索增加模型往返时间。

## 联网核查

2026-10-14 阅读以下公开文档，并在当前网络中请求真实搜索和来源接口：

- [GitHub REST API 限额](https://docs.github.com/en/rest/using-the-rest-api/rate-limits-for-the-rest-api)：未认证主限额为每 IP 每小时 60 次，搜索有额外限额。不能把 GitHub 搜索当作批量任务的唯一入口。
- [SearXNG Search API](https://docs.searxng.org/dev/search_api.html)：支持 `/search?q=...&format=json`，实例必须启用该格式，公开实例不一定提供 JSON。
- [SearXNG 搜索设置](https://docs.searxng.org/admin/settings/settings_search.html)：对验证码、访问拒绝和限流进行来源暂停；本实现记录这些失败，不试图绕过验证码。
- [Brave Search API](https://brave.com/search/api/)：可配置的付费搜索替代品；未配置 key 时完全不调用。此轮实测没有 Brave key，未验证真实付费搜索效果。
- [AWS：Timeouts, retries and backoff with jitter](https://aws.amazon.com/builders-library/timeouts-retries-and-backoff-with-jitter/)：根据下游延迟分位数和可接受误超时率选值，互联网访问还需考虑网络延迟；不照搬文中的区域内 p99.9。这里进一步用证据和模板收益曲线选择总预算。

当前网络探测中，DuckDuckGo 有一次返回 HTTP 202 人机验证，但后续真实样本搜索也有正常结果；
GitHub 也出现 403 限流，因此不能假设任一免费搜索始终可用。公开 PoC-in-GitHub CDN 索引可用。

## 已接入的流程

1. 原有参考页面优先直接读取，避免先调用不可用的 Tavily Extract。
2. 缺少具体 HTTP 证据时，查询公开 PoC 索引、官方 Nuclei 原文，以及配置的 SearXNG 或 DuckDuckGo。
3. 索引没有仓库线索时，尝试 GitHub 仓库搜索；仓库树 API 失败时尝试 GitHub 页面文件列表。
4. 在有界深度、请求数和并发下读取 README、代码和分析文章。搜索片段只作线索，不能单独算请求证据。
5. 免费流程没有 HTTP 证据且预算仍有余量时，可使用 Brave 或 Tavily 搜索。免费优先不代表模型 API 免费。

## 时间选择实验

`scripts/benchmark_discovery_budget.py` 从前一轮 326 个结果的四种状态中各选 4 个样本：
生成模板、没有有效模板、没有参考正文、模型错误。不是随机总体样本，不用于推断总体成功率。

每个 CVE 做一次最长 45 秒的冷抓取，关闭付费搜索，不读取旧爬取缓存。
记录资料到达时间，构造 10/20/30/45 秒时的输入，然后使用真实模型生成模板。
相同提示词复用模型返回，避免把随机生成差异当作时间预算收益。

选择规则：找到同时保留至少 95% 最佳证据支持模板数量、至少 95% 最佳 HTTP 证据覆盖的最短预算。
本轮结果选中 20 秒，已设为默认。这里的 95% 是观察结果的保留比例，不是统计置信度。

| 新增预算 | HTTP 证据 CVE | 格式有效模板 CVE | 严格自动证据支持 CVE |
| --- | ---: | ---: | ---: |
| 10 秒 | 8/16 | 4/16 | 1/16 |
| 20 秒 | 10/16 | 4/16 | 1/16 |
| 30 秒 | 10/16 | 4/16 | 1/16 |
| 45 秒 | 10/16 | 4/16 | 1/16 |

20 秒以上没有观察到模板收益；10 秒损失了两个样本的 HTTP 证据。
部分真实模型调用超时，因此该结果不能证明模板能力充分，也不能证明 20 秒是全局最优。
进一步使用另一组 16 个样本做实际 20 秒截止验证，结果独立写入验证报告。

独立验证结果：15/16 有正文，8/16 有 HTTP 证据，7/16 有格式有效模板，2/16 通过自动证据检查。
5 个活跃抓取到截止时尚未完成。此实验的异步抓取限时 20 秒，外围进程另有 2 秒启动/清理宽限；
生产增强流程的外围硬超时包含在配置的 20 秒总预算内，因此实验覆盖率不能当作硬截止下的保证。
两组实际抽取样本无重叠，模型仍有超时，免费来源的网络表现会变化。

## 产物

- 时间曲线：`output/discovery_budget_20261014/report.json`
- 独立截止验证：`output/discovery_budget_validation_20261014/report.json`
- 每个 CVE 的 `timeline.json` 保留到达时间、公开来源和失败原因。
- `budget_<秒>/<CVE>/` 保存提示词、模型返回、候选 YAML 和静态审查。

静态证据检查要求引用的 URL 是实际抓取来源，引文在该来源中出现，请求路径在该来源中出现。
它不验证参数、负载、版本语义、多步依赖或运行效果，不能代替人工审查。

配置 `REFERENCE_CRAWL_BUDGET` 可以调整默认值（0 禁用新增联网流程，上限 30 秒）。根引用和后续链接共享此预算；超时后保留已完成页面，未取得正文的根引用记录为 unresolved，不视为已证明无证据。
新增预算与原有参考抓取、模型生成耗时分开；任务有可用结果时提前结束，不等满预算。
